Documentazione Ufficiale

Benvenuto nella documentazione di Oryx Swapper. Qui troverai tutte le informazioni tecniche e pratiche per sfruttare al 100% il nostro client-side modifier per Rocket League.

1. Introduzione

Oryx Swapper è uno strumento sviluppato per manipolare in memoria locale i pacchetti grafici (Unreal Packages, estensione .upk) di Rocket League. Non utilizza iniezioni in RAM né software di cheat; si limita a sostituire le geometrie 3D e le texture del gioco scambiando dinamicamente i nomi all'interno dei file originali crittografati.

Nota tecnica: Il sistema sfrutta uno script backend Python che decripta la firma originale del file usando AES, effettua una sostituzione offset-aware nella Name Table del motore Unreal Engine 3, e ricripta il pacchetto mantenendo intatta la validazione di Epic Games.

2. Come funziona lo Swap

L'interfaccia utente è progettata per essere intuitiva. Per eseguire uno swap:

  • Seleziona il Filtro: Scegli la categoria (Body, Boost, Decal, ecc.).
  • Seleziona il bersaglio (Target): Questo è l'oggetto che possiedi già nel tuo inventario e che vuoi sacrificare visivamente.
  • Seleziona il donatore (Donor): Questo è l'oggetto che vuoi visualizzare in game (es. Alpha Boost, Fast 4WD).
  • Clicca Swap: L'applicazione copierà i dati visivi del donatore e li applicherà al file del bersaglio.

3. Il Motore Multi-Variant

A differenza dei vecchi swapper che si limitavano a modificare il file base (es. Boost_Standard_SF.upk), il motore v1.0.0 di Oryx è dotato di un algoritmo di "Smart Discovery".

Quando decidi di swappare un oggetto, l'algoritmo analizza la cartella CookedPCConsole alla ricerca di tutte le possibili varianti legate a quell'oggetto. Ad esempio, il "Boost Standard" possiede diverse varianti di colore (Blu, Verde, Rosa, Giallo) e varianti di texture (pacchetti _T_SF).

Il motore modifica simultaneamente fino a decine di file per garantire che, indipendentemente dal team in cui ti trovi (Arancio o Blu), l'oggetto venga caricato senza crash e con le texture corrette.

4. L'importanza del Revert (Ripristino)

L'applicazione effettua sempre un backup invisibile dei tuoi file originali prima di applicare una modifica. Se desideri cambiare swap, o se il gioco si aggiorna, devi assolutamente usare il tasto Revert.

⚠️ Regola d'oro: Se un oggetto risulta già swappato (confermi dalla presenza del pulsante rosso "Revert"), non puoi swapparlo direttamente in un'altra cosa. Devi prima cliccare su Revert per riportare i file allo stato vergine, e solo dopo procedere al nuovo swap.

5. Sicurezza e Ban

Oryx Swapper opera al 100% in modalità Client-Side. Questo significa che i file vengono modificati unicamente sull'hard disk del tuo PC. I server di Rocket League non eseguono controlli di integrità asincroni sulle mesh grafiche per questioni di performance.

Risultato? Il rischio di ban è inesistente. Tuttavia, tieni presente che gli altri giocatori online non vedranno le tue modifiche, ma continueranno a vedere l'oggetto originale che hai equipaggiato.

6. Risoluzione Problemi

Il gioco non si avvia / "File Corrotto"

Se dopo uno swap il gioco si rifiuta di partire mostrando un errore di verifica di Epic Games:

  • Apri l'app e clicca "Revert" su tutti gli oggetti che hai swappato.
  • Se il problema persiste, vai sul Launcher di Epic Games -> Libreria -> Rocket League -> Gestisci -> Verifica File. Questo ripristinerà tutti i file allo stato originale forzatamente.

I colori sono sbagliati (es. la macchina è tutta nera)

Questo accade di solito con alcune Decals o se non hai ripristinato un precedente swap. Effettua un Revert della macchina e della Decal, avvia il gioco senza swap per assicurarti che tutto sia normale, e poi procedi nuovamente allo swap desiderato con l'app.
