Oryx Documentation

Welcome to the official Oryx Swapper documentation. Here you will find everything you need regarding installation, configuration, and technical troubleshooting.

Installation Guide

Download Oryx Swapper

Download the latest setup file only from the official Discord server.
Do not use reuploaded files, modified versions, or links sent by unknown users.

Run The Setup

Open the Oryx Swapper setup file and follow the installation steps.
If Windows asks for permission, allow it. Oryx needs permission to access and modify local Rocket League files.

Launch The App

After installation, open Oryx Swapper from the desktop shortcut or Start Menu.
The app may ask for administrator permission when launching. This is normal.

Set Your Rocket League Folder

Go to Settings and check the Rocket League folder section.
If the folder is detected automatically, you can continue.
If it is not detected, click Find Automatically or use Browse to select the correct folder manually.

The correct folder should usually look like this:
C:\Program Files\Epic Games\rocketleague\TAGame\CookedPCConsole

Known Issues & Fixes

Before Reporting: Use the latest Oryx version, close Rocket League, run Oryx as administrator, and check the game folder in Settings.

Windows SmartScreen Warning

Windows may warn you because Oryx is not code-signed yet.
Fix: Click More info, then Run anyway, only if downloaded from the official server.

Oryx Does Not Open

Usually caused by antivirus or Windows blocking it.
Fix: Run as administrator, check antivirus quarantine, or reinstall the latest setup.

Rocket League Folder Not Found

Oryx cannot detect your game folder.
Fix: Settings → Find Automatically, or Browse and select CookedPCConsole.

Wrong Game Folder Selected

Swaps will not work with the wrong folder.
Fix: Select Rocket League\TAGame\CookedPCConsole.

Cannot Create Backup

Oryx does not have permission to write in the Rocket League folder.
Fix: Close Rocket League, run Oryx as administrator, then try again.

Source / Target UPK Not Found

A required game file is missing.
Fix: Verify Rocket League files from Epic Games or Steam.

Swap Applied But Nothing Changes

The original item is probably not equipped.
Fix: Equip the item you own in Rocket League, then apply the swap again.

Rocket League Crashes After A Swap

The item may be incompatible or outdated after a game update.
Fix: Use Revert, restart Rocket League, and try another swap.

Revert Does Not Work

Backup may be missing or Oryx lacks permission.
Fix: Run as administrator. If it still fails, verify Rocket League files.

Image Not Available

Oryx has no thumbnail for that item.
Fix: No action needed. It does not affect the swap.

Custom Ball / Decal Does Not Work

The ZIP may be unsupported or imported incorrectly.
Fix: Import the original ZIP directly in Oryx. Do not extract it manually.

After A Rocket League Update

Some swaps may stop working after game updates.
Fix: Revert swaps, verify game files, and wait for an Oryx update if needed.

FAQ

What is Oryx Swapper?

Oryx Swapper is a local cosmetic swapper for Rocket League. It changes how selected items appear on your PC by replacing compatible local game files. It does not give you items, unlock paid content, or modify your Rocket League account.

Do I need to own the item?

Yes. You must own and equip the original item in Rocket League. Oryx only changes how that item appears locally on your PC.

What is the correct swap order?

Choose the item you own first, then choose what you want it to display as.
Example: Standard Boost → Display as Alpha Boost.

Can other players see my swapped items?

In most cases, no. Swaps are local and visual, meaning they are mainly visible on your own PC.

Should Rocket League be open while applying swaps?

No. Always close Rocket League before applying, removing, or reverting swaps. After the swap is finished, launch the game again.

Why did my swap not appear in-game?

Make sure you equipped the original item in Rocket League first. If you swapped Standard Boost to Alpha Boost, Standard Boost must be equipped in-game.

What should I do if Rocket League crashes?

Use Revert in Oryx first. Then launch Rocket League again. If the issue continues, open a support ticket and include the item you swapped, what you displayed it as, and your latest crash log if possible.

Are all items supported?

No. Oryx may not work perfectly with every item. Some items can behave differently, appear incorrectly, or require extra support. If an item does not work, revert it before trying another swap.

How do custom balls and custom decals work?

Custom balls and decals use supported ZIP packs. Import the ZIP directly inside Oryx, apply it, then launch Rocket League. Do not extract the ZIP unless staff tells you to.

Does Oryx create backups?

Yes. Oryx creates backups before changing game files. This allows you to restore the original files if something goes wrong.

What happens after a Rocket League update?

Game updates can change local files. Some swaps may stop working after an update. If this happens, revert your swaps and wait for an Oryx update or staff instructions.

Why does Windows show a warning?

Windows may show a SmartScreen warning because Oryx is not code-signed yet. Only download Oryx from the official server and never trust reuploaded versions.

Where can I get support?

Open a support ticket and explain the issue clearly. Include what you tried, what item you swapped, and whether Rocket League was open or closed.

Safety Info

Download Source

Only download Oryx from the official Discord server.
Do not trust reuploads, modified versions, or files sent by unknown users.

Administrator Permission

Oryx may ask for administrator permission because Rocket League is usually installed inside Program Files.
This permission is needed to create backups and replace local game files.

Local Changes Only

Oryx only modifies local Rocket League files on your PC.
It does not edit your Rocket League account, does not unlock items, and does not communicate with Rocket League servers.

Backups

Oryx creates backups before changing game files.
If something goes wrong, use Revert before trying another swap.

Rocket League Updates

Game updates can replace or change files used by swaps.
After an update, revert your swaps and wait for instructions if something stops working.

SmartScreen / Antivirus

Windows or antivirus software may warn you because Oryx is not code-signed yet.
Only allow the app if it was downloaded from the official server.

Use Carefully

Close Rocket League before applying, removing, or reverting swaps.
Never delete backup folders unless staff tells you to.
