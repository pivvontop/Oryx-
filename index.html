FAQ

Frequently asked questions.

Can other players see my items?

No. The modifications are 100% Client-Side. This means the modified car is only visible on your screen, guaranteeing your account's safety regarding other players and the server.

Does it work with BakkesMod?

We currently recommend disabling BakkesMod's "ItemMod" feature when using Oryx to prevent both programs from trying to write to the same visual memory segment simultaneously.

Why is my antivirus blocking the download?

Programs that "hook" into other processes (like Oryx does with Rocket League) are often flagged as false positives by basic heuristics like Windows Defender. The code is 100% clean and safe.
